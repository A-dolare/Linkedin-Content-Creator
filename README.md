# LinkedIn Content Creator Workflow

> Automated pipeline that transforms topics into evidence-driven LinkedIn posts — research, synthesis, and publishing, all in n8n.

## Overview

This n8n workflow automates the creation of professional LinkedIn thought-leadership posts:

1. **Topic intake** — pulls "To Do" topics from Google Sheets
2. **Research** — Tavily web search for recent, evidence-backed articles
3. **AI synthesis** — structured prompt generates a 150–450 word post with headline, key findings, career impact, skills guidance, hashtags, and optional image recommendations
4. **Image processing** — downloads and converts recommended images to binary (if any pass copyright filters)
5. **Publishing** — posts directly to LinkedIn via OAuth2, with the "IMAGE" media category
6. **Status tracking** — marks the topic as processed in the sheet

## Key Design Decisions

| Feature | Implementation |
|---|---|
| **LLM** | Claude Sonnet via `@n8n/n8n-nodes-langchain.lmChatAnthropic` with `__aiGatewayManaged` routing |
| **Output control** | Structured Output Parser enforces a strict JSON schema (`headline`, `post`, `images[]`, `hashtags[]`) |
| **Image safety** | AI prompt excludes human faces, screenshots, watermarks, and unlicensed media; only data visualizations and CC0 visuals recommended |
| **Evidence grounding** | Tavily search limited to recent articles; AI instructed to cite inline statistics and never invent data |
| **Tone guardrails** | Professional, optimistic, future-focused — explicit exclusion of fear-mongering and clickbait |

## Setup

### Prerequisites

- n8n instance (self-hosted or cloud)
- Google Sheets API credentials (OAuth2)
- Tavily API key
- LinkedIn OAuth2 credentials
- Anthropic API key (or AI Gateway configuration)

### Steps

1. Import this JSON into your n8n instance
2. Create and link the following credentials:
   - `googleSheetsOAuth2Api`
   - `tavilyApi`
   - `linkedInOAuth2Api`
   - `anthropicApi` (or configure the AI Gateway)
3. Replace placeholder values (`SHEET_ID`, `LINKEDIN_PERSON_ID`) with your actual references
4. Test via the **manual trigger** ("Execute workflow")
5. Connect the **Schedule Trigger** node to automate periodic runs

### ⚠️ Known Issues

- `Download Image` URL template uses `{{%20$json.imageurl%20}}` — should reference `{{ $json.output.images[0].url }}` (or iterate the array). Fix the field path before production use.
- `Mark Status in Sheet` writes `Status` back to itself rather than updating it to `"Done"` or `"Published"`. Update the mapping to set `Status = "Published"`.
- `Schedule Trigger` has no outgoing connection in the exported JSON — wire it to `Get row(s) in sheet` to enable cron automation.
- The `HTTP Request` (Tavily direct API call) and `HTTP Request1` (LinkedIn direct API) nodes are **disabled** and can be removed.
